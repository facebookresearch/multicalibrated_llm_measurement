# Multicalibration for Prevalence Measurement

Code and paper for "Multicalibration Is Necessary for Unbiased Model-Based
Prevalence Estimation."

## The Paper

The paper source is `paper/paper.md` (Markdown + Pandoc). A GitHub Actions
workflow automatically recompiles `paper/paper.pdf` whenever changes to
`paper/` are pushed to `main`. To edit the paper, modify `paper.md` and push;
the PDF will be updated automatically.

To compile locally (requires [Pandoc](https://pandoc.org/installing.html) with
citeproc and a LaTeX distribution):

```bash
cd paper
pandoc paper.md -o paper.pdf --citeproc
```

## Setup

### Local (macOS / Linux)

```bash
conda create -n mc_measurement python=3.12 -y
conda activate mc_measurement
pip install -r requirements.txt
```

### Devserver (for GPU inference)

```bash
bash cap_analysis/setup_devserver.sh
source ~/cap_env/bin/activate
```

## Running the Analyses

### 1. Simulation (no external data needed)

```bash
jupyter nbconvert --to notebook --execute simulation/prevalence_bias_simulation.ipynb --output prevalence_bias_simulation.ipynb
```

### 2. ACS Application (downloads ~500MB of Census data on first run)

```bash
jupyter nbconvert --to notebook --execute acs_analysis/acs_exploration.ipynb --output acs_exploration.ipynb
```

### 3. CAP Application (LLM-based policy topic classification)

#### 3a. Prepare data

Downloads 7 datasets from comparativeagendas.net (Denmark, Spain, US, Belgium):

```bash
python cap_analysis/prepare_data.py --proxy http://your-proxy:8080  # omit --proxy if not needed
```

#### 3b. Run LLM inference

Classify ~7K documents (feasibility) or ~105K (full run) using Llama 3.3 70B
Instruct. Requires a GPU with >= 40GB VRAM (A100 recommended) for 4-bit
quantized inference.

**Using a local model checkpoint:**

```bash
python cap_analysis/llm_inference_cuda.py \
  --input cap_analysis/data/feasibility_sample_70b.csv \
  --output cap_analysis/data/inference_output/llama-70b/feasibility_scores.csv \
  --model /path/to/Llama-3.3-70B-Instruct \
  --no-resume
```

**Using HuggingFace Hub (requires access approval and `huggingface-cli login`):**

```bash
python cap_analysis/llm_inference_cuda.py \
  --input cap_analysis/data/feasibility_sample_70b.csv \
  --output cap_analysis/data/inference_output/llama-70b/feasibility_scores.csv \
  --model meta-llama/Llama-3.3-70B-Instruct \
  --no-resume
```

On Apple Silicon (MLX backend, slower):

```bash
python cap_analysis/llm_inference.py \
  --input cap_analysis/data/feasibility_sample_70b.csv \
  --output cap_analysis/data/inference_output/llama-70b/feasibility_scores.csv \
  --model meta-llama/Llama-3.3-70B-Instruct
```

#### 3c. Run analysis

```bash
jupyter nbconvert --to notebook --execute cap_analysis/cap_analysis.ipynb --output cap_analysis.ipynb
```
