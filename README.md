# Multicalibration for Prevalence Measurement

Code and paper for "The Crucial Role of Multicalibration in Model-based Prevalence Measurement."

## Repository Structure

```
mc_measurement/
├── paper/
│   ├── paper.md              # Paper source (Markdown + Pandoc)
│   ├── paper_draft.tex       # Paper source (LaTeX)
│   ├── paper.pdf             # Compiled PDF
│   ├── references.bib        # Bibliography
│   └── images/               # Figures generated by notebooks
├── simulation/
│   └── prevalence_bias_simulation.ipynb   # Simulation study
├── acs_analysis/
│   ├── acs_exploration.ipynb  # ACS empirical analysis
│   └── helpers.py             # Helper functions
├── requirements.txt
└── llm_context.md             # Working notes (not part of paper)
```

## Setup

```bash
conda create -n mc_measurement python=3.12 -y
conda activate mc_measurement
pip install -r requirements.txt
```

## Running the Notebooks

Activate the environment, then run both notebooks:

```bash
conda activate mc_measurement
```

**Simulation** (no external data needed):

```bash
jupyter nbconvert --to notebook --execute simulation/prevalence_bias_simulation.ipynb --output prevalence_bias_simulation.ipynb
```

**ACS analysis** (downloads ~500MB of Census data on first run):

```bash
jupyter nbconvert --to notebook --execute acs_analysis/acs_exploration.ipynb --output acs_exploration.ipynb
```

Or open them interactively:

```bash
jupyter notebook
```

Both notebooks save figures to `paper/images/`.

## Compiling the Paper

Requires [Pandoc](https://pandoc.org/installing.html) with `pandoc-citeproc` support:

```bash
cd paper
pandoc paper.md -o paper.pdf --citeproc
```
